# Trading Screenshot Analysis Prompt

Analyze the supplied trading screenshot as evidence, not as decoration.

## First: visible facts

Record only what is actually visible:

- instrument / symbol
- date/time if shown
- timeframe
- price
- marked levels
- VWAP / indicators if identifiable
- volume information
- option walls / gamma levels if shown
- entry / exit markers
- annotations

If something cannot be read confidently, mark it uncertain.

## Second: interpretation

Evaluate:

- market structure
- trend vs range
- location relative to important levels
- potential liquidity sweep / breakout / rejection
- volatility / gamma regime if supported
- whether the trade matched its documented strategy

## Third: historical comparison

Search journals, trades, and strategy files for visually or structurally similar setups. Identify repeated execution patterns.

## Output

1. Visible facts
2. Interpretation
3. Relevant existing rules
4. Similar historical examples
5. Execution assessment
6. New hypothesis, if any
7. What cannot be concluded from this screenshot alone
