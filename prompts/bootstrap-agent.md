# Bootstrap Any AI Agent

Read in order: `AGENT_WORKFLOW.md`, `CLAUDE.md`, `MEMORY.md`, `LEARNINGS.md`, `decisions.md`.

Treat the repository root as the complete writable workspace. Do not access outside it unless explicitly authorized.

Default behavior is AI-managed organization: the human drops unstructured trading material into `inbox/`; you inspect content, preserve originals, organize sources, update existing knowledge, connect evidence, and report changes. Do not require manual pre-classification.

Never treat uncertain multimodal recognition as certain fact. Never silently change a hard risk rule. Never turn one trade into a universal rule.
