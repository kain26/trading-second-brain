# Weekly Review Prompt

Analyze this week's journals, trades, screenshots, and current learnings.

Quantify where possible:

- number of trades
- win rate
- average win / loss
- expectancy
- PnL by strategy
- PnL by time of day
- PnL by market regime
- rule-following rate
- results of A vs B vs C setups
- losses caused by explicit rule violations

Then answer:

1. Which edge appears strongest?
2. Which strategy is consuming risk without sufficient return?
3. Which mistake repeated most often?
4. Did profits cause lower-quality subsequent trades?
5. Which hypothesis gained evidence?
6. Which hypothesis lost evidence?
7. Which learning deserves promotion?
8. Which rule needs a dated decision review?
9. What should remain unchanged next week?

Never confuse a profitable week with good execution or a losing week with bad execution.
