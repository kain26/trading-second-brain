# Research

Store original research sources here: PDF papers, slide decks, reports, and other reference material.

Workflow:

```text
original source → AI extraction → topic knowledge → later verification
```

Do not replace an original PDF/PPT with an AI summary. Use `prompts/research-extraction.md` and retain page/slide references.

Note: check redistribution rights before committing third-party copyrighted documents to a public repository.
