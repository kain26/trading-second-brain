# Decision Log

An audit trail of changes to trading rules, strategies, and workflow. Never rewrite history; append a new decision when a rule changes.

## Template

### YYYY-MM-DD — Decision title

**Decision:**  
What changed?

**Reason:**  
Why was the change made?

**Evidence:**  
- `journal/YYYY-MM-DD.md`
- `trades/...`
- `screenshots/...`

**Previous rule:**  
If applicable.

**New rule:**  
The exact rule.

**Status:** ACTIVE / TESTING / RETIRED

**Review condition:**  
What evidence would justify revisiting this decision?
